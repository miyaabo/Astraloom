# Phase 5 — Display Experience

## Status

Task 1〜8 の実装と自動検証が完了。次は Human Check として、鑑賞モード・標準モードの UI 自動非表示・表現プリセット・プロジェクター向け表示補正を PC とスマホ実機で確認する。

## Goal

没入を壊さず、星空そのものに集中しやすい表示体験を整える。

1次〜4次で、実際の星空・再生・視点移動・星や星座の知識・天の川と地平線までを実装した。5次ではその上に、鑑賞モード、UI の自動非表示、軽い表現プリセット、プロジェクター利用を意識した表示調整を加え、Product Vision の「情報や UI に邪魔されず夜空へ没入できる」を一段進める。

## Scope(Task 1 で確定 — D019)

- 鑑賞モード
  - 主要な UI をすばやく隠し、星空だけに近い状態へ切り替えられる
- UI 自動非表示
  - 一定時間操作がなければオーバーレイ類を静かに退避し、再操作で再表示する
- 表現プリセット
  - `Planetarium-like` を基準に、方向性を壊さない範囲で **最大 2 種** の軽い見え方切替を持てるようにする
- プロジェクター向け表示補正
  - 暗部つぶれや UI の主張を抑えるための最小限の表示調整を入れる

実装優先順位は以下で確定する。

1. 鑑賞モード
2. UI 自動非表示
3. 表現プリセット
4. プロジェクター向け表示補正

鑑賞モードとプロジェクター向け表示補正は **別機能** として扱う。鑑賞モードは通常のスマホ/PC利用でも使う「UI を静かに退避するモード」、プロジェクター向け表示補正は投影時の暗部つぶれ・UI 可読性を抑えるための個別調整であり、片方がもう片方を内包する前提にはしない。

## Out of Scope(5次では作らない)

- お気に入り・保存・共有・動画出力 — 6次
- アカウント・同期・課金 — 7次/8次
- 惑星・月・代表的天体の位置表示や軌道計算
- 星データソースの差し替えや新規導入
- 天の川・地平線の新しいデータソース導入
- 大規模な設定画面の再設計
- BGM・環境音・スリープタイマー

## Technical Direction

- 既存の星の見た目(shader・`starVisualAttributes`・`starfieldConfig`)を土台にし、表示切替は `starfieldConfig` へ集約する(D004)
- オーバーレイは D009 の方向性どおり星空画面上の最小 UI とし、鑑賞モードや自動非表示でも「必要なときにすぐ戻せる」ことを優先する
- Product Principle 1 と D011 を守るため、表現プリセットは「別アプリのような大きな絵作り変更」ではなく、背景・グロー・ラベル/UI の扱いを軽く調整する範囲に留める。`Planetarium-like` を基準プリセットとし、追加は最大 1 種までを推奨する
- プロジェクター向け表示補正は画像アセットや専用レンダーパスの追加を前提にしない。既存パラメータと UI 表示ルールの調整を第一候補とする

## Acceptance Criteria

### Automated / Technical

- typecheck / lint / unit test / production build が成功する
- 鑑賞モード・自動非表示・プリセット切替の状態遷移を unit test で確認する
- console error なし

### Human Check

- 通常時も鑑賞モード時も、星空が主役である
- UI 自動非表示が不快でなく、再表示も直感的である
- 表現プリセットがプラネタリウム基準から大きく外れていない
- プロジェクター利用を想定したときに、暗部つぶれや UI の邪魔さが増えていない
- PC・スマホ縦画面で破綻しない
