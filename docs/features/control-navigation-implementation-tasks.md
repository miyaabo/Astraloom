## 実装順

状態モデルと共通シェルを先に確立し、その後に既存機能を section ごとに移す。各移行中も、日時・場所・再生・検索・保存・表示設定が失われないことを優先する。

## Task 1 — 操作 UI の状態モデルを再設計する

**Status:** Done

### Goal

サイドパネルの開閉、展開中 section の排他、UI の自動非表示／再表示を、`displayState` に集約する。

### Work

- サイドパネルが開いているか、展開中の section が何かを表す型と純粋な状態遷移関数を追加する
- section は「空を選ぶ」「時間を動かす」「空を探す」「表示・投影」のいずれか 1 つだけを展開できるようにする
- パネルが閉じており、選択情報・フォーム入力がない場合だけ、5 秒後に UI を隠せる条件を定義する
- 星空の空白操作で UI を再表示する状態遷移を定義する
- `displayState.mode` による専用鑑賞モードは、旧 UI を撤去する Task 7 で安全に削除できるよう、以後の統合 UI が依存しない状態モデルにする

### Done

- [x] 状態遷移だけで、パネル開閉・section 排他・自動非表示・再表示を表現できる
- [x] unit test で各状態遷移と自動非表示の抑止条件を確認できる
- [x] 天体選択と UI 再表示の責務が混ざっていない

## Task 2 — ハンバーガーと左サイドパネルを実装する

**Status:** Done

### Goal

### Work

- 左上ハンバーガーと、星空上に重なる左サイドパネルを実装する
- パネル上部に現在の場所・日時の要約を置く
- section の見出しとアコーディオンの共通レイアウトを実装する
- ハンバーガー再タップ、星空の空白操作、Esc キーでパネルを閉じる
- safe area とモバイル縦画面を考慮し、操作要素が画面端やキーボードに隠れないようにする

### Done

- [x] ハンバーガーだけでパネルを開閉できる
- [x] 同時に複数の section が開かない
- [x] PC とスマホ縦画面でパネルが画面外へはみ出さない
- [x] キーボードとタッチ操作で閉じられる

## Task 3 — 「空を選ぶ」を統合する

**Status:** Done

### Goal

現在の日時・場所操作を「空を選ぶ」section へ統合し、調整中も文脈を維持する。

### Work

- 現在の `DateTimeOverlay` と `LocationOverlay` の入力・タイムゾーン・場所プリセット処理をサイドパネルへ移す
- 上部の場所・日時要約を押すと「空を選ぶ」を展開する
- 日時または場所の変更後も section とパネルを閉じず、要約を即時更新する
- 個別の右上入口を撤去する

### Done

- [x] 日時・場所を変更すると星空と要約が正しく更新される
- [x] 遠隔地のタイムゾーンとして日時入力を解釈する既存仕様を維持する
- [x] 変更のたびにパネルが閉じない

## Task 6 — 「表示・投影」と保存を統合する

**Status:** Not Started

### Goal

低頻度の表示設定と保存操作を、サイドパネルに集約する。

### Work

- 夜間モード、プロジェクター補正、フルスクリーンを「表示・投影」section へ移す
- フルスクリーン非対応環境では、現行どおり操作を表示しない

- 保存成功時は panel を閉じず、短い「保存しました」フィードバックを表示する
- `SettingsOverlay` と画面下の `SaveSceneButton` を撤去する

### Done

- [ ] 表示・投影の 3 操作が section 内で機能する
- [ ] 保存後に成功／失敗を分かる形で表示できる
- [ ] 保存時に、場所・日時・再生・視点・表示設定の既存保存範囲を維持する

## Task 7 — 旧 UI を撤去し、保存互換性を確保する

**Status:** Not Started

### Goal

旧入口と専用鑑賞モードを安全に撤去し、既存の保存済みシーンを壊さない。

### Work

- 個別入口（日時、場所、検索、再生、設定、保存、鑑賞モード）の不要なコンポーネント・配線を削除する
- 新しい UI で不要になった `displayState.mode` を、保存と復元を含めて廃止する
- 旧保存データの `mode` フィールドは読み込み時に無視し、standard 表示として安全に復元する
- 一時 UI 状態を保存対象へ追加していないことを確認する

### Done

- [ ] 旧 UI の入口が画面上に残らない
- [ ] 旧保存データを読み込んでもエラーにならない
- [ ] 新規保存データに専用鑑賞モードの状態を含めない
- [ ] 未使用の UI コンポーネントや状態遷移が残らない

## Task 8 — 自動検証と Human Check を完了する

**Status:** Not Started

### Goal

状態遷移と保存互換性を自動で確認し、PC／スマホで実際の鑑賞体験を確認する。

### Work

- typecheck、lint、unit test、production build を実行する
- PC とモバイル viewport で browser smoke test を実行し、console error がないことを確認する
- 5 秒無操作の UI 自動非表示、空白タップでの再表示、天体選択との競合を確認する
- PC とスマホ実機で Human Check を行い、操作を見つけやすいか・UI が星空を邪魔しないかを確認する
- Human Check で問題が見つかった場合は、カテゴリ名・並び・パネル幅・自動非表示時間を必要最小限で調整する

### Done

- [ ] typecheck / lint / unit test / production build が成功する
- [ ] PC／モバイル viewport で console error がない

- [ ] #15 の完了条件と Small Spec の Acceptance Criteria を更新できる

- [ ] パネルを閉じた後、5 秒で UI が自然に退避する
