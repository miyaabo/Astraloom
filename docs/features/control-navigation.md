# 操作・設定導線の再設計 — Small Spec

## Status

要件確定。Task 3（空を選ぶ）まで実装済み。

## Goal

日時・場所・再生・検索・保存・表示設定を、星空への没入を保ったまま迷わず使える一つの操作導線へ整理する。

通常時は最小の入口だけを見せ、操作が不要なときは UI 全体が自然に退避する。現在の個別オーバーレイや独立トグルを、左上のハンバーガーメニューから開く左サイドパネルへ統合する。

## Scope

### 画面の基本状態

- 通常時に表示する恒常的な入口は、**左上のハンバーガーメニューだけ**とする
- 専用の「鑑賞モード」ボタンは廃止する。操作 UI が自動で隠れた状態を鑑賞状態として扱う
- パネルを閉じた後、5 秒間無操作ならハンバーガーを含む操作 UI を隠す
- 星空の空白部分をタップ／クリックすると、隠れた操作 UI を再表示する。天体の選択操作は既存どおり維持する
- パネル表示中、フォーム入力中、選択情報表示中は自動非表示にしない

### メニューの形

- 左上のハンバーガーから、星空上に重なる**左サイドパネル**を開く
- パネル内のカテゴリはアコーディオン形式で展開する。常に 1 カテゴリだけを開けるものとし、別カテゴリを開くと先のカテゴリを閉じる
- パネルは、ハンバーガーの再タップ、星空の空白部分のクリック／タップ、Esc キー（PC）で閉じられる
- PC とスマホで情報構造・開閉規則は共通にする。画面幅・safe area に応じたパネル幅や余白の調整は許容する

### パネルの構成

パネル上部には、現在の場所と日時を要約表示する。要約を押すと「空を選ぶ」を展開する。

| 項目 | 内容 |
|---|---|
| 空を選ぶ | 日時・場所 |
| 時間を動かす | 再生・停止・速度・逆再生・現在時刻へ戻す |
| 空を探す | 星・星座・主要天体の検索、選択、情報表示への導線 |
| 表示・投影 | 夜間モード、プロジェクター補正、フルスクリーン |
| 保存 | 現在の空を保存する 1 回操作 |

- 再生操作は画面下の独立した再生バーに置かず、「時間を動かす」の中で完結する
- 検索は常設入力欄にせず、「空を探す」を開いた場合だけ入力欄と結果を表示する
- 検索結果を選択したらサイドパネルを閉じ、既存どおり選択対象の情報表示へ進む
- 保存後はパネルを閉じず、短い「保存しました」フィードバックを表示する
- 日時・場所を変更してもパネルは閉じない。連続調整を可能にし、上部の要約は即時更新する

## Out of Scope

- 新しい天文・保存・認証・同期・音声機能の追加
- 独立した設定ページ、ルーティング、ユーザー向けレイアウトカスタマイズ
- 星の描画、天文計算、カメラ／再生エンジンの変更
- iOS の Safari 以外で browser chrome を完全に消す D031 の既知制約への対処
- 保存済みシーンの一覧・編集・削除（Phase 9 候補）

## Technical Direction

- UI の構成と開閉状態は `displayState` に集約し、レンダラーや天文計算の責務へ混ぜない
- 日時・場所・検索・再生・表示設定の個別入口は、サイドパネル内の section として統合する。各機能の既存の値・更新処理・バリデーションは可能な限り再利用する
- `displayState.mode` と `ImmersiveModeToggle` は廃止し、既存の自動非表示機構を UI 退避の唯一の仕組みにする。過去の保存データに含まれる `mode` は読み込み時に安全に無視し、以後は保存しない
- `chromeVisibility`、選択中の section、開いているパネル、保存成功表示などは一時 UI 状態であり、Saved Scene の対象に含めない（D020 を維持）
- 夜間モードとプロジェクター補正は Saved Scene の表示設定として従来どおり保存・復元する。フルスクリーンはブラウザ主導の一時状態として保存しない
- キーボードでの操作、既存の `aria-label`、フォーム入力時の focus を保つ。Esc によるパネル閉鎖はフォームの通常操作を阻害しない

## Acceptance Criteria

### Automated / Technical

- typecheck / lint / unit test / production build が成功する
- サイドパネルの開閉、section の排他、UI 自動非表示／再表示、保存成功表示の状態遷移を unit test で確認する
- 既存の保存済みシーンを読み込み、旧 `mode` フィールドの有無でエラーにならない
- PC／モバイル viewport の browser smoke test で console error がない

### Human Check

- 左上の入口から、日時・場所・再生・検索・表示設定・保存を迷わず見つけられる
- パネルを閉じれば星空が主役に戻り、5 秒後の UI 自動非表示が不自然・煩わしくない
- 星空の空白タップでの UI 復帰、天体選択、パネルの閉鎖が競合しない
- スマホ縦画面でパネル内のフォーム、検索結果、再生操作が重ならず操作できる
- 夜間モード・プロジェクター補正・フルスクリーンの入口が「表示・投影」にまとまり、鑑賞体験を妨げない
- PC とスマホで同じ構造として理解できる

## Assumptions

- 初回実装では、カテゴリ名・並び・パネル幅・自動非表示までの秒数は固定値にする
- 実装後は PC とスマホで実際に使用し、操作頻度・発見しやすさ・自動非表示の体感を基に必要最小限の調整を行う
