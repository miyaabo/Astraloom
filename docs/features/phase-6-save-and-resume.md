# Phase 6 — Save And Resume

## Status

Task 1(スコープ確定・Small Spec 作成)完了。6次では、共有や動画出力より先に、**ローカル保存による再開しやすさ** を整える。

前フェーズ: `docs/features/phase-5-display-experience.md`(Done)。1次〜5次で確立した「実際の星空を静かに眺める体験」を、毎回設定し直さず続けられるようにする。

## Goal

気に入った星空体験を保存・再利用できるようにし、鑑賞の継続性を高める。

現時点の Veluna は、場所・日時・再生・視点・星や星座の知識・天の川・地平線・表示体験の整理までを持っている。一方で、アプリを開くたびに状態を作り直す必要があり、「昨日よかった空」「いまの落ち着く表示状態」をすぐ再開できない。6次ではまず、ローカル保存だけで完結する最小の保存体験を整え、バックエンドやアカウントなしで再利用できる状態を作る。

## Scope(Task 1 で確定 — D020)

- **最後の状態から再開**
  - 再読み込みや再訪時に、直前の星空状態を復元できる
- **お気に入りシーンの最小保存**
  - 場所・日時・再生設定・視点・表示プリセットなど、鑑賞に必要な状態を 1 つ以上保存できる
- **ローカル保存**
  - 初手はブラウザ内ローカル保存(`localStorage` を第一候補)で完結させる

### 6次で保存対象に含める候補

- 観測地点
- 日時
- 再生状態(速度、向き。再生中かどうかは Task 2 で要判断)
- カメラの向き/ズーム
- 表現プリセット
- プロジェクター補正

### 6次では保存対象に含めないもの

- 一時 UI 状態
  - 開いているパネル
  - 選択中の説明パネル open/close
  - 自動非表示中かどうか
- その瞬間の一時的な選択情報
  - 選択中の星・星座
- 実データや生成済み geometry のキャッシュ

### 優先順位

1. 最後の状態から再開
2. お気に入りシーンの最小保存
3. 必要最小限の保存 UI

## Out of Scope(6次では作らない)

- 共有リンク
- シーン共有
- スクリーンショット
- 再生動画保存
- アカウント同期
- サーバー保存
- 最近使った場所の履歴管理
- 大規模な保存管理画面

上記は「不要」ではなく、6次の初手では扱わない。特に共有リンク・動画保存・サーバー保存は公開・配布・課金・認可設計へ波及するため、別フェーズで改めて仕様化する。

## Technical Direction

- 保存対象は「星空を再現するための状態」に絞り、UI の一時状態とは分離する
- 初手の永続化はブラウザ内ローカル保存で完結させる。バックエンド・認証・クラウド同期は導入しない
- 保存データは version を持てる構造にし、将来の項目追加や破損データ無視に備える
- 保存導線は D009 の方向性に従い、星空画面上の最小 UI とする。保存機能が主役にならないことを優先する
- 復元失敗時はクラッシュせず、初期状態へフォールバックする

## Acceptance Criteria

### Automated / Technical

- typecheck / lint / unit test / production build が成功する
- 保存用 state の serialize / restore を unit test で確認する
- 破損データや旧形式データを読んでもクラッシュしない
- console error なし

### Human Check

- アプリを開き直したとき、前回の星空に自然に戻れる
- 保存導線が星空鑑賞の邪魔にならない
- 保存したシーンを呼び出しても違和感なく再開できる
- PC・スマホ縦画面で破綻しない
