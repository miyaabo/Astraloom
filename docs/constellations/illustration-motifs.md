# 89星座イラスト用モチーフ・神話一覧

> 88の正式星座に加え、へび座を **へび座（頭）/ へび座（尾）** に分けた **89エントリ** の一覧です。  
> 用途: 星座イラスト生成・レビュー・モチーフ確認。

## 共通方針

- 星座ごとのイラストは、その星座として一般的に認識されるモチーフを優先する。
- 古典ギリシャ神話に基づく星座は、神話上の人物・動物・持ち物が分かる構図にする。
- 近世に定められた器具・科学機器・南天生物の星座は、神話が薄い場合でも名称から正しく認識できる形にする。
- イラスト制作時は、別途生成済みの実データ骨格ガイド画像を参照し、頭・肩・胴・翼・脚・尾・道具の端などが自然に対応するよう調整する。
- 本ファイルはモチーフと意味づけの人間向け正本として扱い、機械処理用JSON/manifestは必要に応じてこの内容をもとに生成する。

## And - アンドロメダ座 / Andromeda
### モチーフ
人物（王女）
### 神話・背景
エチオピア王女アンドロメダ。母カシオペヤの傲慢さが海の神々の怒りを買い、生贄として岩に鎖でつながれたが、ペルセウスに救われた。
### イラストの方向性
鎖につながれた王女。両腕を広げた優雅な立ち姿や、岩に結ばれた姿が一般的。

## Ant - ポンプ座 / Antlia
### モチーフ
器具（空気ポンプ）
### 神話・背景
18世紀にラカーユが定めた新しい星座で、神話由来ではなく当時の科学技術を象徴する空気ポンプを表す。
### イラストの方向性
ポンプ本体、シリンダー、ハンドルなど器具として認識しやすい形。
