# 星空を見ながら、必要な操作と設定を迷わず使えるようにする

**状態:** Draft  
**優先度:** High

## 背景 / Why

日時、場所、再生、検索、保存、鑑賞モード、プロジェクター、夜間 UI が増え、現在の操作導線を一度整理する必要がある。`SettingsOverlay` は最小設定を扱えるが、今後の項目増加を受け止める情報設計は未確定である。

## やること / What

- 現在のオーバーレイ、トグル、パネルを棚卸しする
- PC とスマホ縦画面で、常時見せる操作と隠す操作を決める
- 設定の入口、カテゴリ、パネル形式を Small Spec にする
- 実装対象を小さな後続作業に分割する

## 前提・依存関係

- 既存の `SettingsOverlay`、各オーバーレイ、`displayState` の役割を確認する
- 星空上のオーバーレイを基本とする既存方針を維持する

## 完了条件 / Done

- [ ] ユーザーが必要な操作の場所を把握できる
- [ ] スマホでも操作が密集せず、星空鑑賞を邪魔しない
- [ ] 設定画面の構成と後続作業の範囲が決まっている
- [ ] 既存機能が壊れていない
- [ ] 必要なテストが通る

## やらないこと / Out of Scope

- 大きな別ページの設定画面
- 新しい天文・音声機能そのものの追加
- アカウント管理画面

## Human Check

- PC とスマホ縦画面で日時・場所・再生・検索・保存・表示設定を順に開く
- 閉じた後にすぐ星空へ集中できるか、操作がうるさく見えないかを確認する

## リスク・判断が必要な点

- 設定をまとめすぎると、Calm by Default に反する可能性がある
- ボトムシート、サイドパネルなどの UI 形式は Small Spec で決める

## 参考

- `docs/features/phase-10-atmosphere-presets.md`
- `DEVELOPMENT.md` — Settings Evolution
